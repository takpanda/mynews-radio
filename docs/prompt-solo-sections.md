# 解説台本プロンプトの solo 専用区間（SOLO_ONLY）

2人解説（dialogue）の生成・レビューに、一人解説（solo）専用の指示が混ざらないようにするための仕組みです。
対象は `generate_commentary_script`（解説の台本生成）と `review_synthesize`（レビューの統合）の2つのテンプレートです。

## 基本ルール

- solo 専用の指示は、必ず `<!-- SOLO_ONLY -->` と `<!-- END_SOLO_ONLY -->` で囲んでください。
  - 開始と終了は、それぞれ行の先頭から書き、1 行ずつ分けるのを推奨します。
  - 囲まれていない solo 専用の指示は、既知の表現（例: `1名のみ`、`"{mc_gender}"`、`一人解説の語り口`）に当たらない限り検出されません。
- 開始と終了は交互に並べ、入れ子や逆順にしないでください。
- 囲んだ区間は、solo の生成・レビューではマーカーだけが外され、中身は送られます。dialogue では区間ごと送られません。

## 検出で停止する場合

dialogue の生成・レビューは、次のどちらかに当たると停止します。

- マーカーの対応が崩れている（入れ子、逆順、閉じ忘れ）
- マーカーの外に、solo 専用と分かる表現が残っている

生成は `SoloSectionsUnmarkedError` で停止し、エラーに行番号と該当行を出します。
レビューは dialogue の統合を送らず、元の台本を採用します（`revised=False`）。
solo の生成・レビューは影響を受けません。

## 編集済みの旧版を復旧する手順

既定の区間の文言（区間の開始・終了となる行）を編集した版は、自動では区切れません。次の手順で復旧してください。

1. PC の管理画面で、対象テンプレート（`generate_commentary_script` または `review_synthesize`）を開く。「新しい下書きを作成」の入力欄には最新の版の本文が入っています。最新の版が下書きなど公開中の版と異なる場合は、「版履歴」の公開中の版の本文を入力欄にコピーしてから編集する。
2. エラーに出た行を探し、solo 専用の区間を囲む。
   - 区間は、見出しから、出力例を含む最後の行まで囲みます。
   - 囲みの外に残った solo 専用の指示（例: `話者は "{mc_gender}" 1名のみ`）も、個別に囲みます。
   - 編集した内容はそのまま残してください。書き換える必要はありません。
3. 「下書きとして保存」を押す。この時点では下書きが作られるだけで、生成・レビューにはまだ使われません。
4. 「版履歴」で、保存した下書きの「本番適用」を押す。変更メモ（必須）を入力して確定する。
5. 「公開中」になったことを確認してから、dialogue の生成またはレビューを再実行する。

手順 4 を行わないと、旧版が使われ続けるため復旧しません。

番組別の版は、その番組の dialogue だけに影響します。共通版は、番組別の版が無い番組の dialogue に影響します。

## 既知の限界

- 検出は既知の表現に基づくため、言い換え（例: `話者は男性1人だけです`）は検出されません。solo 専用の指示は、必ず区間で囲んでください。
- 区間の自動付与は、既定の文言が変わっていない旧版にだけ行われます。文言を編集した版は手で囲む必要があります。
